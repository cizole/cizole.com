HealthArchive privacy policy

effective November 21, 2026

HealthArchive is a personal tool that runs only on its owner's computer. It is not offered to the public and has no servers. This policy describes how it handles Google user data.

google data it accesses

HealthArchive requests a single Google permission, drive.file. With it, the tool can access only:

  • Drive folders you explicitly select in Google's folder picker, and
  • files and folders the tool itself creates.

It cannot see or read anything else in your Google Drive.

how that data is used

  • to upload files from folders on your computer into the Drive folder you selected;
  • to read basic metadata of those uploads (name, folder, size, checksum, link) to confirm each copy is complete and to avoid uploading the same file twice.

The tool does not change sharing settings, does not delete Drive files, and does not read files it did not create.

storage

The Google sign-in token, the upload log, and the settings are stored only on the computer running the tool. Nothing is sent to the developer or to any third party. There is no analytics or advertising.

sharing

Google user data is not sold, shared, or transferred to anyone. HealthArchive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

removing access

You can revoke HealthArchive's access at any time at myaccount.google.com/permissions, and delete its local data by removing its data folder.

contact

Questions go to the owner of this website, via the about page.
