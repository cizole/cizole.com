HealthArchive

not a room. a utility closet.

HealthArchive is a small personal tool that runs on one computer. It watches a few local folders and copies finished files from them into a Google Drive folder that its owner chose, then checks that each copy arrived intact.

what it does

  • uploads files from local folders to a chosen Google Drive folder, unchanged
  • verifies each upload by size and checksum
  • keeps a local log so nothing is uploaded twice

what it doesn't do

  • it is not a service. there is no server, no account, and nobody else's data.
  • it can only see Drive items it created or that you explicitly picked.
  • it never shares, sells, or sends anything anywhere except your own Drive.

privacy policy

it is just a script. it would like that noted.
